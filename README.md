# Copy Current URL

A lightweight Microsoft Edge extension that copies the URL of the currently active tab to your clipboard with one click.

## Features

- Copy the current tab URL instantly
- Simple toolbar button
- Toast notification confirming the URL was copied
- No unnecessary tabs or windows
- No tracking or analytics
- No collection, storage, or sharing of browsing data
- Lightweight and easy to use

## How to Use

1. Install the extension in Microsoft Edge: 
https://microsoftedge.microsoft.com/addons/detail/badoonndmoiadkdgmmbkiklemdobcknp
2. Open the webpage whose URL you want to copy.
3. Click the **Copy Current URL** icon in the Edge toolbar.
4. The current tab URL will be copied to your clipboard.
5. A toast notification will confirm that the URL was copied successfully.
6. Paste the URL anywhere using `Ctrl + V` on Windows or `Command + V` on macOS.
